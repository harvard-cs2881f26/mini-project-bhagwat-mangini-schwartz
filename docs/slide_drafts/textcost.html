Text benchmark, 319 items, one run per setting, exact-letter accuracy averaged over the 4 questions (txt0 at thinking minimum, txt1 at default). Every model gets the same prompt, so input tokens are fixed per provider (434k GPT, 459k Gemini, 502k Claude) and cost and latency come from what the model writes. At minimum thinking the smaller models write more per answer than GPT-5 (Nano 116k output tokens vs 70k). Default thinking is where the money goes: GPT-5 Nano writes 724k output tokens (6x) and goes from 49.0% to 66.1% for 4.6x the cost, Mini gains about 5 points, and GPT-5 gets no gain (75.2% to 73.3%) for 3x the cost, which is within noise. The best deal at minimum thinking is Gemini Flash (3): 75.1% vs 75.2% for GPT-5 at 43% of the cost and 77% of the latency. Claude Opus gets about the same accuracy for roughly 4x GPT-5's cost and 2.4x its latency. Gemini's default thinking mostly shows up as hidden thinking tokens, which are saved apart from output tokens and billed as output (about 590k for Flash and 431k for Pro), so latency and cost jump for about +1 point. Caveat: the Claude default-thinking rows are the same replies as the minimum rows, so there is no Claude thinking comparison. Full table is the appendix slide before this one.
