Appendix. What thinking min, default and high actually send to each provider (from the model clients in the repo). OpenAI: min is effort minimal, default sends nothing so OpenAI picks, high is effort high and the output cap goes from 8,192 to 32,768 because reasoning tokens count against it. Gemini 3 and newer: min is level MINIMAL (Pro only goes down to LOW), default sends nothing so the model decides how long to think, high is level HIGH with the cap raised to 40,960. Gemini 2.5 uses a token budget instead (0 at min, 128 for Pro, and 24,576 or 32,768 at high). Claude: no thinking at min or default, so those two are the same request. High turns on extended thinking with a 16,000 token budget, which is a bigger change for Claude than for the others because the paper's Claude runs had no thinking. So "high" is the strongest setting each model offers, not one fixed amount. Thinking tokens are billed as output. Gemini saves them apart from the output token count, so its Out tok column looks small. Source: src/asimov/models/openai_client.py, gemini_client.py, anthropic_client.py.
