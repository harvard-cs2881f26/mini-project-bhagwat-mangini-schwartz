SETUP - One grid, same 319 text items for every cell - Rows = systems, columns = settings, so every comparison is like for like ROWS - Decision models = pick an option instead of writing text (Jev, luna Decisions, OpenJev, Kev-4B, Laya, NLI) - Controls = why decision models behave as they do (below) - Baselines = general LLMs (GPT-5, Mini, Nano, other Fig 4 models) CONTROLS - One question: when a decision model does well, is it because of its decision training, or just because of how it answers? - Kev's own model family (Qwen 4B), one thing changed at a time - Qwen-Base (option probs, one-shot) vs Kev-4B = isolates the decision training (same base model) - Qwen (option probs) vs Qwen generating = isolates how it answers (read probs vs write text), same model COLUMNS (what I varied for the decision models) - Wording: short vs the paper's full wording - Question mode: independent vs cumulative (later questions see earlier answers) - Robustness: letters instead of option names, reversed order, thinking budget (OpenJev), one-shot example (Qwen-Base) COMBINE - Route by confidence (D) = decision model answers, least-sure items go to the LLM - Split by question (B) = decision model takes some questions, LLM the rest - Router search = many combinations, best one per budget SCORED ON (H1's 3 axes) - Accuracy = exact answer per question, mean of 4, 95% CIs - Cost = \$ per 1,000 items (self-hosted: GPU time / params) - Latency = median s per item vs the 2.5 s window - Unreadable answers = decision models have 0 by construction - Next slide: results
