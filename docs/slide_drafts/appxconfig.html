Appendix: setting thinking in a config

Pick one line per setting (greyed = the other choices)

ONE VALUE FOR THE WHOLE RUN

run: repro_fig4_high

benchmark: text

prompt: text_verbatim

thinking: min

thinking: default

thinking: high  # this run

log_reasoning: true

models:

  - {name: GPT-5, provider: openai,

     model: gpt-5}

  - {name: Flash, provider: gemini,

     model: gemini-3-flash-preview}

OR PER MODEL (OPTIONAL, WINS OVER thinking)

models:

  - name: GPT-5

    provider: openai

    model: gpt-5

    reasoning_effort: minimal

    reasoning_effort: low

    reasoning_effort: medium

    reasoning_effort: high

  - name: Sonnet 4.5

    provider: anthropic

    model: claude-sonnet-4-5-20250929

    thinking_budget: 4096  # >= 1024

Appendix. How thinking is set in a run config. Left: one thinking value for every model in the run, either min, default or high (the file is configs/repro_fig4_high.yaml, trimmed to two models). Right: an optional per-model override. reasoning_effort only works for OpenAI models (minimal, low, medium or high) and thinking_budget only for Anthropic models (at least 1024 tokens). Either one wins over the run's thinking value for that model. The config check fails on unknown keys, and on reasoning_effort or thinking_budget with the wrong provider. A new thinking setting needs a new run name, since reusing a run name with a different config stops the run. Source: configs/repro_fig4_high.yaml and src/asimov/config.py.
