Default thinking costs more and doesn’t lift the large model. Small model + default thinking comes close

Action questions are harder than scenario-only questions, and default thinking mostly helps the small model. The bottom row (effect of the action, severity after the action) is lower than the top row for every model, at both thinking settings. Bars are ours: thinking at the minimum each provider allows (txt0) and default thinking (txt1), 319 scenarios, one run. The paper's values are left off this chart for now. GPT-5 gets no gain from default thinking (after-action 66% to 58%, which I have not tested for significance) while its cost goes from $1.24 to $3.68. GPT-5 Nano goes from 56% to 87% on risk type, which is the number the paper reports for it, and uses 6.2x the output tokens ($0.07 to $0.31). It comes close to GPT-5 on risk type (87% vs 93%) and effect (63% vs 64%), but not on severity (59% vs 77%). The paper does not test thinking settings. Model size is shown only as an order (largest, mid-size, smallest) because OpenAI does not publish parameter counts for the GPT-5 models. Only these 3 GPT-5 models are the paper's exact models.
