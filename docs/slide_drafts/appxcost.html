Appendix. Tokens, latency, cost and accuracy for the 8 models on the text benchmark at thinking minimum (txt0) and default (txt1), 319 items, one run each. Out tok is output tokens, p50 is median latency per item, $ is API cost per 319 items, Acc is the mean of the 4 exact-letter accuracies. Input tokens are the same for every model within a provider (434k GPT, 459k Gemini, 502k Claude). The Claude default rows are identical to the minimum rows because the replies were reused, so do not read a thinking effect into them. Gemini saves thinking tokens apart from output tokens and bills them as output, so its default rows look cheap in the Out tok column but are not (Flash about 590k thinking tokens, Pro about 431k). Model names in brackets are the newer models we ran in place of the paper's. Source: results/index.csv.
