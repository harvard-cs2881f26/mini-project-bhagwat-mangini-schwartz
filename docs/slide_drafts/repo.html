Every result comes from one script

One pipeline runs all 3 benchmarks (text, video, image) and every result records how it was made. scripts/run.py takes a YAML config (benchmark, prompt, thinking level, models). The runner (src/asimov/runner.py) is benchmark-agnostic: it caches every API response so reruns are free, records errors without caching them, and scores through a registry. Model clients are one per provider plus a mock. Each benchmark has a loader, a request builder and its own scorer, sharing only the return shape and one answer parser.
