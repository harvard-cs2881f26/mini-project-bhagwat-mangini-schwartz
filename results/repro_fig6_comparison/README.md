# Collected Figure 6-style measurements

`fig6a.png` and `.pdf` follow the paper's horizontal-bar layout, descending violation rate and viridis palette. `fig6a.csv` contains all plotted values, conditions and denominators; `provenance.json` identifies and hashes the source summaries. Plot code is `plot_model_rates` in `scripts/plot_constraints.py`.

All eight displayed conditions returned all 164 responses; malformed outputs are excluded from rates. Three Mini conditions distinguish the user-only baseline, system/user split, and provider-default thinking. Gemini/Claude successor substitutions are labeled. Partial Gemini Flash Preview and unavailable Pro are omitted. Settings differ across bars, so this is a collection of measurements, not a controlled model ranking or exact numerical reproduction.
